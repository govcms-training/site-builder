# Content types

Content types are the **containers** or **templates** for the content on your website.

They’re made up of a fields and settings that you can pick, mix and manage to create a template that fits your content perfectly.

Unlike some other CMSs with strict preset content structures, Drupal allows you to create as many content types with as many fields as you like. Each field can have a different field type. It's up to you to define your information architecture.

Common examples of content types are:

* Basic page
* Blog
* Publication
* News
* Events

Not all content types need to be displayed to a user at a specific URL.&#x20;

For example you can create a content type that is never directly viewed by the audience but is instead displayed in a searchable list, like a list of Freedom of Information requests, or a list of committee members.

The content types configured on the training website are:

* Alert
* Consultation
* Event
* Page
* Webform
