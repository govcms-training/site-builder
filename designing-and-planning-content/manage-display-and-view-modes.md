# Manage display and view modes

### Manage display

Manage display allows you to set how fields should appear to your website visitors, including their field label and their order.

Hover over **Structure**, then **Content types**, then your desired content type and select **Manage display**.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-07 at 1.57.48 pm.png" alt="" width="563"><figcaption></figcaption></figure>

{% hint style="info" %}
The Field Group module can also be used here the same as in the Manage form display section.
{% endhint %}

Using the select options and the row drag widget on the left, we can customise how each of the fields will display.

{% hint style="info" %}
The options configured here **might** be overruled by any theme templates your developers have created.
{% endhint %}

### View modes

View modes let you re-use content, but easily display it differently depending on how the page is requested to be displayed.

This is best explained by checking out the **Event** content type's **Manage display** page.

You'll notice along the top under the first tab navigation of **Edit**, **Manage fields**, etc., that we have **Default**, **Navigation card**, **Promo Card** and **Slider slide**.

Each of these are different view modes.

Navigating between them we can see that:

* **Default** (the view mode used when viewing a node) is set up to use Layout Builder
* **Navigation card** and **Promo Card** both have the same fields in the enabled section
* **Slider slide** has an additional field and the settings for body are trimmed.

For example, if we have a requirement to display events in a slider, but without any attachments or the table of contents, then we can request events using the **Slider slide view mode**, and it will present **ONLY** the fields configured in the view mode.

{% hint style="info" %}
We'll return to this concept in more depth later when we manage media and create a view.
{% endhint %}
