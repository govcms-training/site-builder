# Creating a content type

In this lesson we'll create a new content type for our website.

First, go to **Structure**, **Content types** and select **Add content type**.

<figure><img src="../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

Enter in the **Name** of the content type followed by a short **Description**. The description is only ever shown on the content type landing page and not visible to website visitors.

In this example let's create a content type for **Speakers** presenting at my events.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-06 at 4.42.57 pm.png" alt=""><figcaption></figcaption></figure>

Below the description there are four additional sections.

### **Submission form settings**

**Submission form settings** contain options for the title and preview settings.&#x20;

First, the **Title** field label. This allows you to set the label of the title field. Usually leaving this as Title is fine, however since this content type is about a person, we will use **Name**.

You can also choose if a user must preview the content before saving and publishing.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-06 at 4.44.53 pm.png" alt=""><figcaption></figcaption></figure>

### **Publishing options**

**Publishing options** allows you to set default options for when a new piece of content is created.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-06 at 4.45.12 pm.png" alt=""><figcaption></figcaption></figure>

### **Display settings**

**Display settings** controls whether the author’s name is displayed at the top of a page when viewed.

This is usually turned off on government websites.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-06 at 4.46.05 pm.png" alt=""><figcaption></figcaption></figure>

### **Menu settings**

Finally **Menu settings** provide the ability to define which menus this content type can be added into, as well as what the default top level item will be.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-06 at 4.46.55 pm.png" alt=""><figcaption></figcaption></figure>



Once you have configured these options, select **Save and manage fields**. This takes you to the **Manage fields** screen where you'll be shown your empty content type.
