# Exercises

After the above lessons you should have learnt:

* What a theme in Drupal is
* How pages use regions and blocks
* How roles and permissions are used in Drupal

### Exercise 1 <a href="#exercise-1" id="exercise-1"></a>

Locate the **Block Layout page**, and demonstrate the block regions. Take note of each of the regions, then view a page and see if you can match each block to its region.

### Exercise 2 <a href="#exercise-2" id="exercise-2"></a>

Locate the **Block library** and take note of the available blocks. In the next section we'll create a new block.
