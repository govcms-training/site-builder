# Layout of a Drupal page

As mentioned, every page in Drupal is made out of **regions** and **blocks**. Regions are defined in the theme in code and cannot be altered via the GovCMS administration backend. Blocks can be created via the user interface (UI) and are covered in the next section.

To view your theme's regions, go to **Structure** and then **Block layout** and select **Demonstrate block regions**.

For the training environment, it will look like this:

<figure><img src="../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>

Each of the yellow highlighted regions is a rectangle that you can place content into via a block.

Some blocks display menus, others display images, and some blocks display your page content. No matter how the data is saved it will be displayed by a block in a region.

We cover [Blocks](blocks-in-govcms.md) in the next section.
