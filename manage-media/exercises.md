# Exercises

After the above lessons you should have learnt:

* More information about the media module in Drupal
* How different media types are used and configured
* About image styles and how they can be used to format images
* How to customise a view mode.

### Exercise 1

Add a new field to a media type:

* Edit a media type and add a new field
* Customise the form display to position the field
* Customise the **Manage display** to hide the field.

### Exercise 2

Create a new image style:

* Create a new image style
* Resize and crop an image
* Apply another image style that alters the display.

### Exercise 3

Create a new view mode and implement an image style:

* Create a new view mode for media images
* Customise that view mode to use your new image style
* Implement that view mode on a content type to view your image style.
