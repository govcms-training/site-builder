# Exercises

After the above lessons you should have learnt:

* How URL aliases and redirects work in Drupal

### Exercise 1

* Add a URL pattern for the **Speaker** content type. If a URL pattern already exists, update the existing pattern to something else.
* Go to Bulk Generate and choose the option **Regenerate URL aliases for all paths.**
* View a **speaker** content page and verify that the new pattern has been used.
* Create a new **speaker** content page and verify that the new pattern has been used.

### Exercise 2

* Edit an existing **speaker** content page and add a URL redirect.
* Visit the URL redirect and verify that you're automatically redirected to the new path.
