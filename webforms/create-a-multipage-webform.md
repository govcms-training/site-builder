# Create a multipage webform

Creating multipage webforms can be tricky due to the unique structure of the fields.

In this example, we'll create a multipage webform with some advanced features.

First, create a new webform and add the title of Multipage webform.&#x20;

<figure><img src="../.gitbook/assets/Screenshot 2026-07-28 at 1.22.44 pm.png" alt="" width="563"><figcaption></figcaption></figure>

Select **Save**.&#x20;

Next, add a few standard text fields with unique names.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-28 at 1.30.26 pm.png" alt=""><figcaption></figcaption></figure>

Select the blue **Add page** button.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-28 at 1.33.24 pm.png" alt="" width="375"><figcaption></figcaption></figure>

Enter a page **Title** and select **Save**. Do the same again.

This will create **two page container elements** in the field structure.

Using the **drag widgets**, click and drag the page and elements around to **form a nested structure**.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-28 at 1.34.48 pm.png" alt=""><figcaption></figcaption></figure>

Once the structure is complete, select **Save**.

You can now view your form by selecting the **View** tab.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-28 at 1.38.26 pm.png" alt="" width="563"><figcaption></figcaption></figure>

Here we can see the multipage webform in action.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-28 at 1.40.38 pm.png" alt="" width="563"><figcaption></figcaption></figure>

There are also a few settings that control how the form behaves and how the controls at the top work. Select the **Settings** tab, and then **Form**.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-28 at 1.46.13 pm.png" alt="" width="563"><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/download (5).png" alt="" width="375"><figcaption></figcaption></figure>

**Conditionals** also work across pages, so decisions users make on page 1 can affect which fields appear on later pages.
