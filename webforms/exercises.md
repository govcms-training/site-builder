# Exercises

After the above lessons you should have learnt:

* About webforms
* How to create a multipage webform
* How to create conditional email handlers

### Exercise 1

* Create a multipage webform that collects feedback.
* Add fields such as name, age (integers from 18 to 40), gender and an attachment field.
* Add a conditional body field that's only shown if a user selects an age above 30.
* Set up three email handlers:
  * Send an email conditionally to an email address if the age is above 30.
  * Send an email conditionally to another email address if the age is below 30
  * Send an email conditionally to another email address if the age is 30.
* Test your webform to verify the conditional logic works as expected.
