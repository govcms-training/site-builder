# Exercises

After the above lessons you should have learnt:

* About taxonomy
* How to create a new taxonomy vocabulary and add terms
* How to add a taxonomy reference field to a content type
* The different taxonomy field widgets.

### Exercise 1

Create a new taxonomy vocabulary.

* Go to the taxonomy landing page and add a new taxonomy vocabulary
* Add or remove custom fields you may want to collect
* Customise the form display to only the fields you want
* Add terms to your vocabulary.

### Exercise 2

Add taxonomy field to a content type.

* Edit an existing content type and add a reference to your new taxonomy vocabulary
* Configure your field based on your imaginary requirements
  * Does the content author need to create new terms?
  * Do they need to select a single or multiple terms?
* Try different form widgets to get a different user experience.

### Exercise 3

Create some new test content with your new term. We'll use this later when we create our search view.
