# Taxonomy input widgets

Depending on the field options, there are a number of different taxonomy input widgets available.

### Autocomplete

Allows the user to type in a string and be presented with a list of matching suggestions.

If the user can only select one value, they'll be shown a single field like this:

<figure><img src="../.gitbook/assets/Screenshot 2026-07-13 at 4.32.12 pm.png" alt="" width="563"><figcaption></figcaption></figure>

However if the user can select multiple values, they'll be presented with an option to **Add another item**, like the screenshot below.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-13 at 4.35.01 pm.png" alt=""><figcaption></figcaption></figure>

### Autocomplete (tag style)

Allows the user to type in a string and be presented with a list of matching suggestions (similar to the first input above), with multiple values allowed using a comma separation.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-13 at 4.33.08 pm.png" alt="" width="563"><figcaption></figcaption></figure>

### Select list

Suitable for selecting a single value from a large list (10+ items).

<figure><img src="../.gitbook/assets/Screenshot 2026-07-13 at 4.32.50 pm.png" alt="" width="410"><figcaption></figcaption></figure>

### Check boxes/radio buttons

Suitable for selecting either a single or multiple value input. While it can take up a lot of screen real estate if there are lots of terms, you can style the admin interface to display them in columns to use less space.

The field will automatically swap to radio buttons if the user can only select a single value.
