# How to use taxonomy terms

The simplest way to see content that has been tagged with a taxonomy term is to return to the **taxonomy vocabulary** page. Go to **Structure**, **Taxonomy** and select **State and Territories**, and you'll see the list of terms.

<figure><img src="../.gitbook/assets/image (58).png" alt=""><figcaption></figcaption></figure>

By selecting a term directly from the vocabulary you can automatically see all items that have been tagged with that term.

By selecting Australian Capital Territory, we can see two test items that contain that term.

<figure><img src="../.gitbook/assets/image (59).png" alt="" width="563"><figcaption></figcaption></figure>

If we then return to the list and select **New South Wales**.

<figure><img src="../.gitbook/assets/image (60).png" alt="" width="563"><figcaption></figcaption></figure>

We can now see the single item tagged with New South Wales.

Now that you've added a taxonomy to a content type, you can use those taxonomy values elsewhere in your website.

{% hint style="info" %}
It's very rare that a government website will allow users to visit the taxonomy term landing pages like shown above. Instead, taxonomy terms are usually used to create search filters or custom lists.
{% endhint %}

We'll use taxonomy terms later [when creating a View](../content-listing-with-views/create-a-view.md).
