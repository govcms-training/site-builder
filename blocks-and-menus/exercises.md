# Exercises

After the above lessons you should have learnt:

* How to control a block's visibility
* How to create and place blocks
* An overview of menus in Drupal
* How to use the Context module

### Exercise 1

Create a new **component block** and place it in a region on your website. Ensure to customise either the URL paths or content type it's displayed on.\
\
Change the visibility settings to see how these can be used to dynamically display content.

### Exercise 2

Create a new menu and assign it to a content type.&#x20;

Add some menu links to the menu, including nested menu links.

Place you new menu in a region using the automatically created menu block. Change the block display options to hide/show the menu block depending on what page you're visiting.

### Exercise 3

Create a new context that adds a custom component block to the top of all pages for Content Authors to give them links to an agency style guide.
