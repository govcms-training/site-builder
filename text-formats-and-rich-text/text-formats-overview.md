# Text formats overview

When you're editing a large text area field, you're probably using a **text format**.

<figure><img src="../.gitbook/assets/Screenshot 2026-07-14 at 11.06.33 am.png" alt=""><figcaption></figcaption></figure>

This functionality (sometimes referred to as **WYSIWYG**\*) provides a toolbar similar to common document editing toolbars.

The options available in the toolbar are defined in a **text format**.

### How can they be used

It can be useful to have different text formats configured for your website to help your content authors input the correct information into the correct field.

For example, you may have a text field used as the text on a display card, where you want users to be able to add bold, italics and links, but you don’t want them to embed any media.

That would use a different text format to your standard body field that requires all the available functions including media.

### What options can be configured

Many of the same options available in modern document editing tools such as Microsoft Word are available for configuration, such as **Bold**, _Italics_, [links](text-formats-overview.md#what-options-can-be-configured), tables, headings and lists.

There are also additional tools that are more relevant to a website, such as the ability to interlink between pages in Drupal, embed media assets, or add additional CSS classes to style content.
