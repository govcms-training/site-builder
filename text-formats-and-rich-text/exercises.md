# Exercises

After the above lessons you should have learnt:

* An overview of Text formats
* How to customise the toolbar of a WYSIWYG editor
* All the available toolbar options

### Exercise 1

Setup a new text format.

* Create a new text format
* Limit the available buttons
* Configure your plugins and filters.

### Exercise 2

Implement your text format.

* Create a new field, or edit an existing text field and implement your new text format
* Create or edit content and test your new input format.

{% hint style="info" %}
If you change an existing fields format and only provide a new more restrictive format, any content that doesn't fit that format will be stripped from existing fields. Be careful.
{% endhint %}
