# What this manual covers

This training manual covers the following topics:

* How Drupal lays out a page
* What a theme is and does
* Blocks
* Site navigation
* Roles and permissions
* Content types
* Fields
* Paragraphs
* Media
* Text formats
* Views
* URL aliases and redirects
* Search
* Site performance



Each section also contains various exercises to put your new-found knowledge to use.

There is also a collective challenge exercise at the end that will test all your learned skills in a real-world example.

### Interchangeable terms

Drupal and GovCMS have a lot of terminology, and sometimes frustratingly we can use different words to mean the same things. For example:

* Page, Content, Node
* Paragraph, Component
